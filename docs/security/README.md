# Security Documentation

Current security documentation for Career Learning Hub:

- [Current Gemini Threat Model](CURRENT_GEMINI_THREAT_MODEL.md)
- [Phase 15 Security and Privacy Checklist](PHASE_15_SECURITY_PRIVACY_CHECKLIST.md)

The current release uses authenticated ownership, private asset controls, server-side Gemini credentials, validated AI output, durable background-job safeguards, rate limiting, CORS controls, request validation, Request IDs and sensitive-data logging restrictions.

The Phase 20A final evidence record is the authoritative final-release qualification record. Security regression testing is evidence of implemented controls; it is not a penetration test or formal security certification.
