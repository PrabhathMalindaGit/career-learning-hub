# University Evaluation Source Boundary

University-evaluation evidence should use:

- the submitted PID for original aims, objectives, methodology and planned evaluation;
- the submitted Interim Report for the interim-stage implementation and verification record;
- the Phase 20A final evidence freeze for final implementation, automated qualification and human QA evidence;
- current architecture, security, testing and deployment documentation for final technical explanation.

Earlier development-history artifacts are not part of the final academic narrative. The final report should describe Career Learning Hub directly as the integrated authenticated application delivered for the project.

PID and Interim checkpoint facts should not be retroactively rewritten merely because the final implementation later advanced. Final-stage evidence must clearly distinguish interim checkpoint evidence from final evidence.
